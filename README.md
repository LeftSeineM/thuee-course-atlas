# 课程去向地图

清华电子本科课程、研究问题与产业应用的静态探索网站。学生项目，非院系官方系统。

## 内容

- 10个核心课程模块：上下段归并浏览，中英文/替代课程保留课程号和学分。
- 官网2023目录公开版的77条专业课程记录；保留版本与选项边界。
- 30门专业限选课程，数理基础与实验实践课程。
- 6个研究方向、9个应用切口，涵盖音频、推荐、数字芯片、模拟电路、通信、雷达、光通信、机器人与实时音视频。
- 每个应用包含企业官方来源、工作任务、课程联系、自选项目、研究延伸和待补能力。

## 本地运行

纯HTML/CSS/JavaScript，不需要安装依赖。运行 `python -m http.server 8769` 后访问浏览器；也可以直接打开index.html。

## 发布

GitHub Pages 从 main 分支根目录发布。所有资源均使用相对路径，支持项目子目录部署。

## 内容维护

`data.js`是浏览器数据，`catalog.json`是同一内容的可读数据副本。更新时同步两者。来源与核对日期在sources字段；浏览模块和原始课程记录分开保存。不可将替代选项学分直接累加。

目前没有取得可确认适用于2024—2026级的完整公开培养方案。企业案例用于理解工作，非在招岗位推荐或就业保证。应用联系、小项目为编辑整理，待教师与专业人员继续校核。

本仓库只包含网站代码和整理后的课程数据，不包含实践报告、录音、个人文件或账号凭据。
